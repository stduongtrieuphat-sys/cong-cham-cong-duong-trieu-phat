# Cổng chấm công - Công ty Dương Triệu Phát

Nhân viên: Lê Hiền, Linh.

## Chạy bản server
1. Cài Node.js 20+.
2. Mở Terminal trong thư mục này.
3. Chạy `npm install`.
4. Chạy `npm start`.
5. Mở `http://localhost:3000`.

Tài khoản demo:
- Lê Hiền / 1234
- Linh / 1234
- Admin / admin123

Dữ liệu nằm trong `data.json` trên server. Nhân viên không có API sửa/xóa bản ghi; chỉ Admin mới có quyền quản trị.

Bản này là starter để triển khai thật. Khi đưa lên Internet nên bật HTTPS, đổi mật khẩu mặc định, dùng database production và backup định kỳ.
